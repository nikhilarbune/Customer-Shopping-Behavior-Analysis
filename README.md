# Customer-Shopping-Behavior-Analysis
## Project Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across different product categories. The main objective is to identify spending patterns, customer segments, product preferences, subscription behavior, and other business insights that can support better decision-making.

## Dataset

- Rows: 3,900
- Columns: 18
- Customer Demographics: Age, Gender, Location, Subscription Status
- Purchase Details: Item Purchased, Category, Purchase Amount, Season, Size, Color
- Shopping Behavior: Discount Applied, Promo Code Used, Previous Purchases, Frequency of Purchases, Review Rating, Shipping Type
- Missing Values: 37 values in Review Rating

## Data Cleaning & Preparation

Python and Pandas were used for data preparation and exploratory analysis.

- Loaded the dataset using Pandas
- Performed initial data exploration using `df.info()` and `df.describe()`
- Checked missing values
- Handled missing Review Rating values using the median rating of each product category
- Standardized column names using snake_case
- Created `age_group` based on customer age
- Created `purchase_frequency_days`
- Checked redundancy between `discount_applied` and `promo_code_used`
- Removed the redundant `promo_code_used` column
- Loaded the cleaned dataset into PostgreSQL

## SQL Analysis

PostgreSQL was used to perform business-oriented SQL analysis.

### Key Analysis

1. Revenue generated by male vs. female customers
2. Customers who used discounts but spent more than the average purchase amount
3. Top 5 products based on average review rating
4. Average purchase amount comparison between Standard and Express shipping
5. Comparison of subscribers vs. non-subscribers
6. Products with the highest percentage of discounted purchases
7. Customer segmentation into New, Returning, and Loyal customers
8. Top 3 products in each category
9. Relationship between repeat purchases and subscription status
10. Revenue contribution by age group

## Power BI Dashboard

An interactive Power BI dashboard was created to visualize the analysis.

### Dashboard Features

- Total Customers
- Average Purchase Amount
- Average Review Rating
- Customers by Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group
- Gender Filter
- Category Filter
- Subscription Status Filter
- Shipping Type Filter

## Key Insights

- Male customers generated higher total revenue than female customers.
- Express shipping had a higher average purchase amount than Standard shipping.
- Loyal customers represented the largest customer segment.
- Young Adults contributed the highest revenue among the age groups.
- Certain products showed higher discount dependency.
- Top-rated products were identified using average review ratings.
- Subscription behavior was compared with repeat purchasing patterns.

## Business Recommendations

- Boost subscriptions by providing exclusive subscriber benefits.
- Introduce loyalty programs to reward repeat customers.
- Review discount strategies while maintaining healthy profit margins.
- Promote top-rated and best-selling products.
- Use targeted marketing for high-revenue customer segments.
- Focus on customers with strong repeat-purchase behavior.
